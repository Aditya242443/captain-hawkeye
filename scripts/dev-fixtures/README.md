# Historical Development Fixtures (Dev-Only)

This directory contains historical test data, synthetic generators, and standalone prototype files used during early isolated development.
These files are preserved for reference and testing, but are **NOT** part of the live Project Plexis application execution path.

- `sightings.json`: Synthetic sightings dataset originally used by the trajectory prototype.
- `generate_data.py`: Script that generated the synthetic `sightings.json` dataset.
- `verify_all.py`: Test assertions written against the synthetic JSON fixture.
- `preview.html`: Early prototype standalone map preview.
